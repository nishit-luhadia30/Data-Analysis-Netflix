# Professional Resume Bullets: Netflix Analytics Portfolio Project

**Target Roles:** Senior Data Analyst | Analytics Engineer | Business Intelligence Consultant  
**Core Stack:** Python (pandas, scipy, seaborn) | SQL (SQLite) | Power BI (Star Schema, DAX) | Data Governance  

---

### High-Impact Resume Bullets (Action $\rightarrow$ Context $\rightarrow$ Tool $\rightarrow$ Quantified Impact)

- **Engineered an end-to-end data pipeline and 5-table star schema** in SQLite for 584 Netflix Original titles, constructing a normalized bridge table for 51 multi-genre films and developing a suite of 12 analytical SQL queries leveraging CTEs, window functions (`LAG`, `NTILE`, `ROW_NUMBER`), and automated integrity tests that achieved 100% referential consistency.

- **Conducted rigorous non-parametric statistical testing and data auditing** in Python (`scipy.stats`), detecting and correcting a legacy index-misalignment bug in genre runtimes (+29.04m error on 159 documentaries), establishing that runtime is statistically uncorrelated with perceived quality ($\rho = -0.0221$, $p = 0.593$), and proving genre quality variations are statistically significant via Kruskal-Wallis test ($H = 168.87$, $p < 0.001$).

- **Designed an enterprise 3-page Power BI dashboard package and consulting executive briefing** (Situation-Complication-Answer framework), architecting 10+ robust DAX measures (`DISTINCTCOUNT`, YoY mature growth, acclaim share) and isolating key content vulnerabilities across 8 standardized genre groups—revealing that Documentaries lead catalog quality (6.93 avg, 55.8% rated $\ge 7.0$) while Comedies suffer a 31.4% sub-5.5 quality deficit.
